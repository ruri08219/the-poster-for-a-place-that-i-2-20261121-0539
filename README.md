A small program that writes one image to `/output/entry.png`: a vintage travel poster for **VELMARA**, a place that does not exist — a cliff-top lighthouse town above a glowing turquoise bay at golden dusk, under two moons, white sailboats on calm luminous water. The invented place's name is set into the picture in large cream serif capitals; there is no other copy on the poster. The image itself ships in this repo as `entry.jpg`; the script simply places an exact copy where the runner expects it, so what you see here is exactly what gets judged.

## Run it

```sh
python3 main.py
```
